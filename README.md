# Canadian Coin Grader — Clean Release

Version propre destinée à Streamlit Community Cloud.

## Fichiers
- `app.py` — application Streamlit
- `grading_engine.py` — moteur de grading et calibration par références
- `reference_feature_index.csv` — banque de 473 références canadiennes gradées
- `requirements.txt` — dépendances
- `README.md` — ce fichier

## Streamlit
Lors de la création de l'application :
- Repository : votre nouveau repository GitHub
- Branch : `main`
- Main file path : `app.py`

Aucun fichier `v2` n'est requis et aucun renommage n'est nécessaire.
